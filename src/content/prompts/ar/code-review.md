مراجعة كود بعين ثانية قبل الدفع (Push) أو الدمج (Merge)، مفيدة جدًا لو تشتغل لحالك بدون فريق مراجعة.

## متى تستخدمه
- قبل عمل Pull Request بمشروع فريق
- لما تشك بوجود مشكلة أمنية بكود حساس (دفع، مصادقة)
- لتعلم أفضل الممارسات بلغة برمجة معينة
