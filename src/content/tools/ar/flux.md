FLUX عائلة نماذج توليد وتحرير صور من شركة **Black Forest Labs** الألمانية، أسسها فريق كان وراء نماذج Stable Diffusion الأصلية. الفرق الجوهري بينها وبين Midjourney إنها **مو منتج، هي نماذج**: توصل لها عبر واجهة برمجية، أو تنزّل الأوزان وتشغّلها على جهازك.

هذا يعني حرية أكبر وتكلفة أقل للاستخدام المتقطع — ومسؤولية إعداد أكبر عليك.

## نسخ FLUX.2 والفرق بينها

| النسخة | الوضع | متى تستخدمها |
|---|---|---|
| **klein** | مفتوحة Apache 2.0 | تجارب، كميات كبيرة، تشغيل محلي مجاني |
| **dev** | أوزان مفتوحة، تجاري برخصة | لما تبي تشغّل نموذج قوي على بنيتك أنت |
| **pro** | عبر API | الخيار الافتراضي لأغلب الأعمال |
| **flex / max** | عبر API | أعلى جودة، للمخرجات النهائية |

## ليش يتميّز؟

- **النص داخل الصورة:** أفضل نقطة قوة فيه. اللافتات والملصقات والأغلفة تطلع بحروف إنجليزية سليمة، وهذي مشكلة مزمنة عند أغلب المنافسين.
- **التحرير بالأوامر:** ترفع صورة وتقول "بدّل الخلفية لمكتب حديث" — نفس النموذج يحرّر، ما تحتاج أداة ثانية.
- **الواقعية:** البشرة والإضاءة والانعكاسات من الأقرب للطبيعي بين النماذج المتاحة.
- **التكلفة:** تدفع بالصورة. لو تولّد 50 صورة بالشهر، هذا أرخص بكثير من أي اشتراك.
- **الاستقلالية:** لأن النسخ المفتوحة موجودة، ما أنت رهينة قرار شركة ترفع السعر أو تغلق الخدمة.

## طريقة الاستخدام

1. اختر طريقتك: منصة وسيطة تدفع فيها بالصورة، أو واجهة BFL البرمجية، أو تشغيل محلي عبر ComfyUI
2. اختر النسخة المناسبة (Klein للتجربة، Pro للعمل، Max للنهائي)
3. اكتب البرومبت بالإنجليزي ووصّف الإضاءة والعدسة والأسلوب بوضوح
4. لتحرير صورة موجودة، ارفعها واكتب التعديل المطلوب بلغة عادية
5. ولّد النسخة النهائية بأعلى دقة تحتاجها — السعر يزيد مع الدقة

## لمن يناسب؟

**يناسبك لو** كنت مطورًا تبني منتجًا يولّد صور، أو مصممًا يحتاج نصوصًا دقيقة داخل الصور، أو تولّد كميات كبيرة وتبي تتحكم بالتكلفة، أو مهتمًا بتشغيل نموذج على جهازك بدون اشتراك.

**ما يناسبك لو** تبي أداة تفتحها وتستخدمها فورًا بدون إعداد، أو تحتاج نص عربي داخل الصورة، أو يهمك مجتمع ومعرض تستلهم منه — هنا Midjourney أنسب بمراحل.

## حدود مهمة

الرخص هي أكثر نقطة تلخبط الناس: **Klein** مفتوحة وواضحة، **dev** أوزانها مفتوحة لكن الاستخدام التجاري عليها يحتاج رخصة شهرية مدفوعة، و**pro/max** عبر API بشروط المزوّد. قبل أي مشروع تجاري، اقرأ رخصة النسخة اللي بتستخدمها بنفسك — الفرق بينها مو تفصيل بسيط.
