GitHub Copilot هو مساعد البرمجة اللي يسكن داخل المحرر اللي تستخدمه أصلًا. ما فيه محرر جديد تتعلمه ولا طريقة شغل تعيد بناءها — يظهر كنص رمادي قدام المؤشر وتضغط Tab عشان تقبله.

هو أول أداة من نوعها بهذا الحجم، ولين الحين أقل طريقة احتكاك لإضافة الذكاء الاصطناعي لبيئة تطوير موجودة.

## وش يميزه فعلًا؟

- **يتوافق مع محررك الحالي:** VS Code و JetBrains و Visual Studio و Neovim و Xcode
- **اقتراحات مباشرة بدون احتساب رصيد** بالخطط المدفوعة — الميزة اللي تستخدمها مئات المرات باليوم ما تكلفك شي
- **يقرأ المستودع للسياق،** فالاقتراحات تمشي على أعراف مشروعك بدل أنماط عامة من الكتب
- **وضع الوكيل** ياخذ مهمة مكتوبة ويعدّل عدة ملفات ويفتح طلب دمج تراجعه أنت
- **مراجعة كود تلقائية** تعلّق على طلبات الدمج قبل ما يوصلها بشري
- **مجاني للطلاب الموثقين** ولمطوري المستودعات مفتوحة المصدر المشهورة

## كيف تستخدمه؟

1. ثبّت إضافة Copilot بمحررك وسجّل دخول بحساب GitHub
2. اكتب تعليق يوصف اللي تبيه وابدأ تكتب — الاقتراحات تظهر بنص رمادي
3. اضغط Tab للقبول، Esc للتجاهل، Alt+] للتنقل بين البدائل
4. افتح Copilot Chat لأسئلة عن كود موجود أو لشرح ملف ما تعرفه
5. استخدم وضع الوكيل للمهام اللي تمتد على عدة ملفات مو دالة وحدة

## نصايح تطلّع نتيجة أفضل

- **علّق قبل ما تكتب كود.** تعليق واضح فوق دالة فاضية هو أقوى طريقة توجّه فيها الاقتراح
- **خلّ الملفات المرتبطة مفتوحة** — Copilot يقرأ التبويبات المفتوحة كسياق، ففتح ملف النموذج أو التعريفات يغيّر اللي تحصله
- **احتفظ بالشات للأسئلة الحقيقية** بعد ما صار محسوب؛ استخدم الاقتراحات للكتابة الروتينية
- **راجع دائمًا ولا تثق أبدًا.** يكتب كود منطقي بثقة، بما فيه كود يستدعي دوال ما هي موجودة أصلًا
- **أضف ملف `.github/copilot-instructions.md`** عشان توثّق أعراف مشروعك مرة وحدة بدل ما تكررها

## لمين مناسب؟

**مناسب لك لو** عندك محرر ترتاح عليه، تكتب كود فيه تكرار كثير، تشتغل بعدة لغات، طالب (مجاني لك)، أو تبي مساعدة ذكية بدون تغيير طريقة شغلك.

**مو مناسب لك لو** تبي ذكاء اصطناعي يقود إعادة هيكلة معمارية كبيرة — Cursor و Windsurf مبنيين لهذا — أو لو شغلك بلغات نادرة تنزل فيها جودة الاقتراحات.

## حدوده وتحذيرات

**الرصيد ينفد.** بعد تغيير الفوترة بيونيو 2026، استخدام الشات والوكيل محسوب. المستخدمين الكثيفين يوصلون السقف قبل نهاية الشهر بخطة الـ10$.

**يكتب كود خاطئ بثقة،** بما فيه استدعاء دوال ما هي موجودة. كل اقتراح يحتاج قراءة قبل القبول.

**راجع إعداد بيانات التدريب** بالخطط الفردية قبل ما تستخدمه على شغل ملكية خاصة.

## بدائل

**Cursor** الخيار الأقوى للشغل الكبير على عدة ملفات وهو مسار الترقية الأشهر. **Windsurf** يقدّم نهج وكيل مشابه بواجهة أنظف. **Claude** أفضل لما تبي شرح أو مراجعة أو نقد للكود بدل إكمال تلقائي.
