ChatGPT is a conversational AI assistant built by OpenAI. It can answer questions, write content, summarize text, help with code, and analyze images and files. It's one of the most widely used AI tools in the world, suitable for beginners and professionals alike.

## How to use it

1. Go to chat.openai.com and create a free account (email or Google)
2. Type your question or request in the text box
3. Upload images or files using the attachment icon
4. Enable "Search" before sending to get up-to-date web results
5. To upgrade, click "Upgrade" in the sidebar menu
