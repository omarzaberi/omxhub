Microsoft Copilot is an AI assistant built to work alongside everyday Microsoft apps, helping you draft documents, analyze Excel data, summarize Teams meetings, and quickly draft emails.

## How to use it

1. For basic use: go to copilot.microsoft.com with a Microsoft account (free)
2. To use it inside Word or Excel: open the app and click the Copilot icon in the ribbon (requires a Microsoft 365 Copilot subscription)
3. Type your request in plain language (e.g. "summarize this report" or "build a table from this data")
